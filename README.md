# Documentación Arquetipo

## Descripción

Este proyecto base actúa como un arquetipo para la creación de microservicios con el framework NestJS. Ofrece una estructura inicial y configuraciones comunes para simplificar el desarrollo e implementación de microservicios, alineándose con principios y patrones de arquitectura de software.
